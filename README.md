# 形式原理視覺實驗室

供七年級視覺藝術課使用的第一版視覺與互動原型。學生透過「觀察 → 比較 → 診斷 → 修正」理解漸層；目前只有「漸層」開放，其他形式原理只呈現樣本縮圖與「即將開放」。

## 啟動方式

本專案是無後端、無資料庫、無外部 API 的靜態前端網站，可直接部署至 GitHub Pages。

1. 在專案根目錄啟動任一靜態檔案伺服器，例如 `python -m http.server 8765`。
2. 在瀏覽器開啟 `http://localhost:8765/`。

核心功能不依賴網路。若直接雙擊 `index.html`，部分瀏覽器會因 ES module 安全限制阻擋資料載入，因此建議使用本機靜態伺服器。

## 檔案結構

- `index.html`：網站進入點與基本中繼資料。
- `styles.css`：全站設計變數、響應式版面、互動與減少動態效果設定。
- `data.js`：形式原理、題目、答案、提示、說明、圓點數量與大小等資料。
- `app.js`：頁面元件、路由、答題狀態、點擊、拖曳、觸控與鍵盤互動。
- `screenshots/`：三種尺寸的驗收截圖。

## 學習單名稱差異

正式學習單使用「反覆」，本次需求清單使用「重複」；學習單另有「單純、調和」，本階段指定的八項清單未列。依照需求，本版不自行替換名稱，仍顯示：重複、漸層、對稱、均衡、對比、律動、比例、統一。

## 增加其他形式原理

1. 在 `data.js` 的 `principles` 陣列調整該原理的 `status`、說明與縮圖圓點資料。
2. 在 `tasks` 增加題目、答案、提示、說明與圓點資料。
3. 在 `app.js` 增加對應的任務渲染函式，沿用 `taskFrame()`、共用按鈕、回饋與畫布樣式。
4. 將新頁面加入 `route()` 的雜湊路由表。

目前資料與畫面已分離，新增原理時不需要重寫首頁或樣本牆元件。

## 第一階段範圍
